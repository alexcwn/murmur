Field recorder, not a theme

Two decks, one token set. Light is a cream-and-silver faceplate in the Marantz PMD register; dark is matte black with aluminium trim, closer to a TC-D5. Neither is an inversion of the other — both are machines that actually existed.

Needle ballistics are a real spec

A VU meter reaches 99% of a steady tone in 300 ms and falls at the same rate — that's the standard, and it's why analogue meters feel weighted rather than twitchy. The needles above use it. A digital bar graph tracking instantaneous amplitude looks nothing like this, which is the whole point of asking for a needle.

06

Motion

Mechanical, not decorative. A key travels and stops; it does not ease elegantly into place.

motion.keyTravel60 ms — button press and release
motion.state120 ms — panel and status changes
motion.needleRise300 ms — VU standard integration time
motion.needleFall300 ms — symmetric, per the same standard
motion.peakHold1200 ms — then the peak marker drops
motion.easecubic-bezier(0.2, 0, 0, 1)

Reduced motion

Under prefers-reduced-motion the needle stops animating and reads instantaneous level as a static position; the peak marker still updates. Level information is never conveyed by motion alone.

Murmur Design Tokens v1 — 1980s field recorder. Tokens map one-to-one onto a Swift Tokens enum; every view reads from it and no component declares a literal value. Archivo and Azeret Mono ship inside the app bundle.
